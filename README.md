## 🛠️ Как подключиться к RCON Minecraft-сервера?

Для того чтобы настроить удаленное управление сервером, вам необходимо активировать и настроить протокол RCON. 

### Пошаговая инструкция:

1. Перейдите в корневую директорию вашего сервера и откройте файл `server.properties` через любой текстовый редактор.
2. Найдите в тексте следующие параметры и приведите их к нужному виду:

* **`enable-rcon=true`** — обязательно включите этот параметр (выставите значение `true`), чтобы разрешить удаленные команды.
* **`rcon.password=ВАШ_ПАРОЛЬ`** — придумайте и установите сложный пароль для защиты вашего сервера.
* **`rcon.port=25575`** — укажите порт для подключения (по умолчанию используется `25575`, но вы можете выбрать свой).

---
⚠️ **Важно:** После сохранения изменений в файле `server.properties` обязательно **перезапустите сервер**, чтобы настройки вступили в силу.
