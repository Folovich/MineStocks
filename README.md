## 🛠️ Как подключиться к RCON Minecraft-сервера?

Для того чтобы настроить удаленное управление сервером, вам необходимо активировать и настроить протокол RCON. 

### Пошаговая инструкция:

1. Перейдите в корневую директорию сервера и открой файл `server.properties`.
2. Найдите в тексте следующие параметры и приведите их к нужному виду:

* **`enable-rcon=true`** — напиши значение `true`
* **`rcon.password=ТВОЙ_ПАРОЛЬ`** — пароль для  сервера.
* **`rcon.port=25575`** — (по умолчанию используется `25575`, но можешь выбрать свой).

---
⚠️ **Важно:** `rcon.password` лучше сделать длинным и сложным.
