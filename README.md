## 🛠️ Как подключиться к RCON Minecraft-сервера?

Для удалённого управления Minecraft-сервером необходимо активировать и настроить протокол RCON.

### Пошаговая инструкция:

1. Перейди в корневую директорию сервера и откройте файл `server.properties`.
2. Найди следующие параметры и приведите их к нужному виду:

- `enable-rcon=true` — включает RCON.
- `rcon.password=ТВОЙ_ПАРОЛЬ` — пароль для подключения.
- `rcon.port=25575` — порт RCON (по умолчанию `25575`).

---

⚠️ **Важно:** Используй надёжный пароль. Не открывайте порт RCON для свободного доступа из интернета.

## 🛠️ Как включить moex stocks?

### Linux

1. Откройте папку `moex_stock`.
2. В файле `moex_stocks.py` найдите строку:

```python
RCON_HOST, RCON_PORT = "IP", PORT
```

- Вместо `IP` укажите адрес Minecraft-сервера. Для локального сервера используйте `127.0.0.1`.
- Вместо `PORT` укажите порт RCON.

3. Установите переменную окружения с паролем:

```bash
export RCONS_PASSWORD="Пароль"
```

4. Запустите программу:

```bash
python3 moex_stocks.py
```

---

⚠️ **Важно:** Параметр `server-ip` в `server.properties` не обязательно указывать в `RCON_HOST`. Для локального сервера обычно используется `127.0.0.1`.

---

### Windows

1. Откройте PowerShell.
2. Перейдите в папку `moex_stock`:

```powershell
cd "ПУТЬ\MineStocks-main\moex_stock"
```

Замени `ПУТЬ` на фактический путь к папке проекта.

3. Установите переменную окружения:

```powershell
$env:RCONS_PASSWORD="Пароль"
```

4. Запустите программу:

```powershell
python moex_stocks.py
```

---

⚠️ **Важно:** Переменная окружения доступна в текущем окне PowerShell и программах, запущенных из него. После закрытия окна её потребуется установить заново.

## ⚙️ Настройка moex stocks

- `POLL_SECONDS = 60` — интервал обновления котировок в секундах.
- `RCON_HOST` — адрес Minecraft-сервера.
- `RCON_PORT` — порт RCON.
- `TICKERS` — список отслеживаемых акций. Через запятую добавляем "биржевой тикер":"название".

## 📝 Примечания

### MOEX stocks

Получение котировок через API Московской биржи (MOEX ISS).

Программа получает текущие цены акций через API Московской биржи (MOEX ISS), рассчитывает процентное изменение относительно цены открытия текущей торговой сессии и отправляет результаты в чат Minecraft через RCON.

Результаты последней проверки сохраняются в `out/quotes.json`.
